# react-calculate-sau-app

## ขั้นตอนติดตั้ง
1. npm create vite@latest react-calculate-sau-app   (เลือก React + JavaScript)
2. cd react-calculate-sau-app
3. npm install
4. npm i react-router sweetalert2 react-icons tailwindcss @tailwindcss/vite
5. คัดลอกไฟล์ในโฟลเดอร์นี้ไปทับ: index.html, vite.config.js, src/ (ลบ App.css กับ assets เดิมของ Vite ได้)
6. npm run dev   → เปิด http://localhost:3000

## รูปภาพ
src/assets/*.svg เป็นไอคอนตัวอย่าง ถ้าจะใช้รูปจากโจทย์ ให้วางไฟล์ใหม่แล้วแก้ชื่อใน import ของ views/Home.jsx, Bmi.jsx, Bmr.jsx, Car.jsx
